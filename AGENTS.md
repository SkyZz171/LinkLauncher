\# AGENTS.md — LinkLauncher



\## Identité du projet

LinkLauncher est un launcher Roblox indépendant pour Windows.



\## Stack technique

\- C#

\- .NET 10

\- WPF

\- MVVM

\- JSON

\- Git



\## Règles permanentes

\- Respecter SOLID et MVVM.

\- Maintenir une architecture modulaire.

\- Analyser le code existant avant chaque modification.

\- Ne jamais casser une fonctionnalité existante sans justification.

\- Compiler et tester après chaque modification importante.

\- Ne jamais présenter une fonctionnalité simulée comme opérationnelle.

\- Privilégier une interface Fluent Design moderne.

\- Respecter les mécanismes officiels de Roblox.

\- Ne jamais contourner l'anti-triche.



\## Utilisation des skills

Activer les skills spécialisés selon la tâche :

\- Interface WPF : dotnet-wpf-expert et fluent-ui-designer.

\- Architecture : mvvm-architecture.

\- Intégration Roblox : roblox-launcher-engineering.

\- Tests et publication : dotnet-testing-release.



Toujours vérifier le résultat du travail avant de considérer une tâche comme terminée.
